# 패의 반란 – 반란전 공식 규칙 v0.1 (초안)

## 0. 게임 정체성
- **패의 반란**은 의도적으로 불공평한 계급사회 카드게임이다.
- 상위 계급은 구조적으로 유리하고, 하위 계급은 불리하다.
- 하위 계급은 불리함을 감수하며 **반란 게이지**를 축적해 역전 기회를 만든다.

## 1. 구성 요소

### 1-1. 카드 덱 (반란전 고정)
총 80장:
- 군주 1
- 대공 2
- 공작 3
- 기사장 4
- 재무관 5
- 사제 6
- 길드장 7
- 상인 8
- 농노 9
- 부랑자 10
- 추방자 11
- 반역자 12
- 광대 2

카드 강도(강 → 약):
**군주 > 대공 > 공작 > 기사장 > 재무관 > 사제 > 길드장 > 상인 > 농노 > 부랑자 > 추방자 > 반역자**

### 1-2. 플레이어 계급 (최대 8단계)
- 군주
- 대공
- 기사장
- 재무관
- 길드장
- 농노
- 추방자
- 반역자

인원수(4~7인)에서는 상/하위 계급 우선으로 일부만 사용한다.

### 1-3. 인원별 플레이어 계급 매핑 (확정)
- 4인: 군주 / 대공 / 추방자 / 반역자
- 5인: 군주 / 대공 / 농노 / 추방자 / 반역자
- 6인: 군주 / 대공 / 기사장 / 농노 / 추방자 / 반역자
- 7인: 군주 / 대공 / 기사장 / 길드장 / 농노 / 추방자 / 반역자
- 8인: 군주 / 대공 / 기사장 / 재무관 / 길드장 / 농노 / 추방자 / 반역자

## 2. 라운드 구조

한 게임은 여러 라운드로 진행된다.  
각 라운드는 아래 순서:

1) 계급 확인  
2) 카드 분배  
3) 세금(카드 교환)  
4) 광대 기본 계급 지정  
5) 시작 플레이어가 첫 판 시작  
6) 턴 플레이(손패 소진 경쟁)  
7) 라운드 순위 확정 및 다음 라운드 계급 재배정

## 3. 시작 규칙

### 3-1. 첫 라운드 시작 플레이어
- 모든 플레이어가 다이스를 굴린다.
- 최고 눈 플레이어가 시작권 획득.
- 동률 시 동률자 재굴림.

### 3-2. 2라운드 이후 시작 플레이어
- **군주**가 시작 플레이어.

## 4. 카드 분배 규칙

- 반란전은 항상 **80장 전부 사용**.
- 모든 카드를 분배한다.
- 균등 분배 후 남는 카드는 **하위 계급부터 1장씩 추가 지급**.

예시:
- 4인: 20/20/20/20
- 5인: 16/16/16/16/16
- 6인: 상위 4명 13장, 하위 2명 14장
- 7인: 상위 4명 11장, 하위 3명 12장
- 8인: 10장씩

## 5. 세금(카드 교환) 규칙

세금은 **2라운드부터 적용**.

### 5-1. 기본 교환 페어
- 반역자 ↔ 군주 : 2장
- 추방자 ↔ 대공 : 1장
- 농노 ↔ 기사장 : 1장  
(해당 계급이 없는 인원수에서는 존재하는 페어만 적용)

### 5-2. 제출/반환 방식
- 하위 계급: 정해진 장수만큼 제출(강제)
- 상위 계급: 같은 장수만큼 원하는 카드 반환

### 5-3. 광대 세금 규칙
- 광대는 **강제 제출 대상 아님**
- 하위 계급이 원하면 광대를 세금으로 제출 가능
- 광대 1장 세금 제출 시 반란 게이지 **+3**
- 일반 카드 1장 세금 제출 시 반란 게이지 **+1**

## 6. 광대 규칙

### 6-0. 광대 계급 지정 타이밍 (명문화)
- 광대의 기본 계급 지정은 **세금(카드 교환) 완료 직후** 진행한다.
- 즉, 한 라운드의 처리 순서는 `카드 분배 → 세금 교환 → 광대 계급 지정 → 첫 판 시작`이다.
- 1라운드는 다이스 시작권 플레이어가 지정하고, 2라운드부터는 군주가 지정한다.


### 6-1. 라운드 기본 계급 지정
- 매 라운드 시작 시 광대의 기본 계급 1개를 지정한다.
- 1라운드: 다이스 시작권 플레이어가 지정
- 2라운드 이후: 군주가 지정

### 6-2. 사용 방식
- 광대 단독/광대끼리 낼 때: 해당 라운드 **지정 계급**으로 취급
- 일반 카드와 함께 낼 때: **함께 낸 일반 카드 계급**으로 취급

예:
- 광대 기본 계급이 재무관일 때 광대 1장 단독 = 재무관 1장
- 농노 2 + 광대 1 = 농노 3장

## 7. 턴 진행 규칙

플레이어 턴 행동:
1) 카드 제출
2) 패스

### 7-1. 카드 제출 규칙
- 한 번에 내는 카드는 동일 계급 n장(광대 포함 가능)
- 이미 판에 카드가 깔린 상태라면:
  - **같은 장수**
  - **더 강한 계급**
  을 만족해야 제출 가능

### 7-2. 패스 규칙
- 패스 가능
- 한 번 패스하면 현재 판이 끝날 때까지 재참여 불가

### 7-3. 판 종료
- 마지막 제출자를 제외한 활성 플레이어 전원이 패스하면 판 종료
- 마지막 제출자가 다음 판 시작권 획득
- 패스 상태 초기화 후 새 판 시작

### 7-4. 탈락(손패 0장)
- 손패를 먼저 0장 만든 순서대로 라운드 순위 확정
- 손패 0장 플레이어는 이후 턴에서 제외
- 마지막 1인 남으면 라운드 즉시 종료(자동 최하위)

## 8. 라운드 종료 및 계급 재배정

- 라운드 순위(1등~꼴찌)에 따라 다음 라운드 계급 부여
- 다음 라운드 세금/시작권/게이지는 새 계급 기준 적용

## 9. 반란 게이지 규칙 (v0.1: 획득만 확정)

> 능력 사용처는 후속 버전에서 확정한다.
> 사용 능력 시스템은 추후 개발 항목이며, 실제 도입 여부도 후속 의사결정으로 분리한다.

### 9-1. 최대치
- 최대 12

### 9-2. 라운드 시작 게이지
- 군주 0
- 대공 0
- 기사장 1
- 재무관 1
- 길드장 2
- 농노 2
- 추방자 3
- 반역자 3

### 9-3. 획득 조건
1) 세금 제출
- 일반 카드 1장: +1
- 광대 1장: +3

2) 패스 보상
- 군주/대공/기사장: +0
- 재무관/길드장: 패스 시 +1 (라운드 최대 1회)
- 농노/추방자/반역자: 패스 시 +1 (라운드 최대 3회)

3) 덮임 보상
- 농노/추방자/반역자의 제출 패가 덮였을 때 +1
- 라운드 최대 2회

### 9-4. 이월 여부
- 라운드 종료 시 게이지 초기화
- 다음 라운드 시작 게이지를 새로 적용
